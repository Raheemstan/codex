# Frontend Pages & Components (Next.js App Router)

## Public
- Landing page with hero, how it works, specialists, trust badges, pricing, testimonials, CTA.
- SEO metadata, schema.org health service markup.

## Auth
- Login / register / email verification / password reset.

## Patient
- Dashboard: upcoming appointments, history, notifications.
- Booking flow: select specialization → consultant → timeslot → payment.
- Chat room + video session entry.
- Medical profile & prescription downloads.

## Consultant
- Dashboard: upcoming appointments, earnings.
- Availability management.
- Consultation room with notes + prescription panel.

## Admin
- Admin analytics dashboards inside Payload admin.
- Settings + overrides.

## UI considerations
- Mobile-first.
- Dark mode.
- Multi-language (i18n routing).
