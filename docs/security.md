# Security & Compliance

## Authentication
- JWT access tokens with short TTL.
- Refresh tokens stored securely.
- Enforce MFA for admin.

## Data protection
- Encrypt medical records (notes, files).
- Field-level permissions in Payload.
- Audit logs for sensitive actions.

## Abuse prevention
- Rate limiting at API gateway.
- WAF rules for common attacks.

## Compliance
- Data residency options.
- Consent management for recording and data exports.
- Patient data export / deletion flows.
